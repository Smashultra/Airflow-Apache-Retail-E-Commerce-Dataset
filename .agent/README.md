# Shared Agent State

This directory stores compact, tool-neutral project state shared by human contributors and coding agents.

- `HANDOFF.md`: latest verified state, risks, and next action.
- `TODO.md`: current work, owner, branch, and dependency.
- `DECISIONS.md`: durable decisions and their rationale.
- `PLANS.md`: rules and template for execution plans.
- `plans/active/`: plans currently being executed.
- `plans/archive/`: completed or cancelled plans.

Git history and pull requests remain the audit trail for individual file changes. Do not copy raw command logs into this directory.
