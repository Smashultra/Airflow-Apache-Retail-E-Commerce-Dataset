# Contributing

## Workflow

1. Read `AGENTS.md` and the current `.agent` state.
2. Claim the task in `.agent/TODO.md`.
3. Create a short-lived branch for the task.
4. Keep commits scoped and explain why the change is needed.
5. Run the relevant checks and record them in the pull request.
6. Update `.agent/HANDOFF.md` at integration or handoff checkpoints.

Suggested commit prefixes: `feat`, `fix`, `docs`, `test`, `refactor`, and `chore`.

Do not combine generated files, datasets, or unrelated formatting with functional changes.
